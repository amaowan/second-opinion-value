`a1_results.json` is the output of `experiments/a1_three_layer_kaggle.py` (run of 21 November 2026) that every number in the paper is computed from.

To add the per-item tables, copy `a1_items_*.npz` from the output of the same Kaggle notebook into this folder. They hold labels, probabilities and predicted classes for the test split of each task, and no text.
